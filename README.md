# GenLayer QuizGame

This is a simple mini-game concept built for GenLayer.

## Idea

QuizGame is a replayable community quiz where users submit answers and earn points for correct responses.

## Features

- onchain answer submission
- wallet-based score tracking
- replayable game rounds
- simple leaderboard logic

## Game Flow

1. Read the question
2. Submit an answer
3. Correct answers earn points
4. Scores are stored per wallet

## Purpose

This project demonstrates how GenLayer Intelligent Contracts can be used to build simple multiplayer-style community games.

## Future Ideas

- weekly reset
- leaderboard ranking
- AI-generated questions
- XP rewards system
